Dữ liệu mẫu / chưa có API

  • "Cập nhật 3 ngày trước": API chưa có updated_at (số mẫu).
  • "Khách hợp với căn này 3": chưa có API ghép khách (số mẫu).
  • Tên chủ nhà: chưa có API. Số điện thoại chủ nhà không hiển thị trên mockup (nút Gọi dùng tel: thật khi chạy).
  • Địa chỉ, toà nhà, tiện ích, điểm nổi bật: dữ liệu bịa. Dải ảnh nhỏ và số ảnh "1/6": ảnh thật chưa có (photo_urls rỗng), photo_count có trong API.

Lệch so với prompt màn

  • Không có trạng thái "rỗng" (một đối tượng); có thêm "Không tìm thấy (404)" theo prompt.
  • Theo phản hồi chủ dự án: ba ô thông số của prompt thành lưới 6 ô có icon (thêm phòng tắm, tầng, tiền cọc; bỏ khỏi cụm "Thông tin thêm"); thêm dải ảnh nhỏ + ô đếm ảnh; khối giá nổi bật.
